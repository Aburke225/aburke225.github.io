# aburke225.github.io

Personal website, served by GitHub Pages at https://aburke225.github.io.

## Editing

Everything lives in `index.html` — no build step. Push to `main` and GitHub Pages redeploys automatically within a minute or two.

- **Resume**: drop a `resume.pdf` into the repo root; the Resume button already points at it.
- **Links**: LinkedIn and YouTube URLs are near the top of the `<nav class="links">` block.
- **Projects**: duplicate a `<li class="project">` block per project; swap the "Coming soon" badge for a real link when a site goes live.
